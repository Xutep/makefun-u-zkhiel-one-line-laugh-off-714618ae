Entry for the [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae)
bounty on make.fun.

`main.py` (Python 3, standard library only) writes exactly one funny line
to `/output/entry.txt`:

> My alarm clock dumped me. It said I kept hitting snooze on our relationship.

Run it with:

```sh
python3 main.py
```

It is deterministic: the same line every run, no network, no randomness.
